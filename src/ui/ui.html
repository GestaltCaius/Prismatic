Mods folder

The Mods folder inside your Stardew Valley folder. Pick one of the usual places or type the full path. It is remembered in this browser, unless the program was started with -d, which always wins.

Nexus cookie

checking

Downloads from Nexus Mods need your nexusmods_session cookie. Prismatic tries the NEXUS_COOKIE variable, then your browser's cookies. To use another one, open nexusmods.com signed in, then in the browser developer tools go to Application (Chrome) or Storage (Firefox), Cookies, and copy its value. A pasted cookie wins over the automatic ones until you forget it. It is kept in this browser and sent only to this local program. Treat it like a password.
